## Atividade

Para validar o conteúdo foi feito um quiz: `Gestão de Projetos e História do Vale do Silício`
### 1. No início do vídeo, Leland Stanford contrata o fotógrafo Muybridge e paga pelo experimento para descobrir como os cavalos correm. Qual é o papel de Stanford nesse projeto?
- [ ] Gerente do Projeto
- [x] **Patrocinador (Sponsor)** ✅
- [ ] Cliente final sem autoridade
- [ ] Programador

---

### 2. O cientista William Shockley tinha um estilo de liderança muito duro e controlador. Isso fez com que seus 8 principais funcionários pedissem demissão juntos. O que esse caso ensina sobre projetos?
- [ ] O líder não precisa entender do assunto técnico.
- [x] **Liderança ruim e ambiente tóxico destroem a equipe do projeto.** ✅
- [ ] Salário é a única coisa que segura uma equipe.
- [ ] Projetos de tecnologia não precisam de pessoas.

---

### 3. Os antigos aviões e mísseis usavam válvulas de vácuo, que esquentavam muito e quebravam direto. Trocar as válvulas pelos novos transistores de silício ajudou o projeto a:
- [ ] Aumentar os custos sem necessidade.
- [x] **Reduzir o risco de falha nos equipamentos.** ✅
- [ ] Atrasar as entregas para o cliente.
- [ ] Complicar o trabalho dos engenheiros.

---

### 4. Antes mesmo do Google existir formalmente como empresa, os fundadores receberam um cheque de 100 mil dólares de um investidor. Para que serve esse dinheiro no projeto?
- [ ] Para pagar uma multa por atraso.
- [x] **Para ser o orçamento inicial e cobrir os custos do projeto.** ✅
- [ ] Para encerrar o projeto e demitir a equipe.
- [ ] Para comprar a empresa concorrente.

---

### 5. Em 1957, a União Soviética lançou o satélite Sputnik. Isso levou os Estados Unidos a correr para criar a NASA e acelerar seus projetos. Qual impacto isso teve nos prazos dos projetos americanos?
- [ ] Os prazos ficaram mais longos e calmos.
- [x] **Criou-se um prazo limite (deadline) urgente para entregar os resultados mais rápido.** ✅
- [ ] Os projetos foram todos cancelados.
- [ ] O tempo de entrega deixou de ser importante.

### 6. Quando os criadores do Google desenvolveram o site de busca, focaram apenas em entregar o melhor resultado de pesquisa, sem poluir a página com notícias e anúncios confusos. Essa atitude é um exemplo de:
- [x] **Foco e controle de escopo (fazer apenas o que foi planejado).** ✅
- [ ] Desvio de escopo (fazer coisas fora do combinado).
- [ ] Erro de programação no site.
- [ ] Falta de orçamento para o projeto.

### 7. Para construir um míssil ou um foguete espacial, os engenheiros precisam dividir o projeto inteiro em partes menores (motor, navegação, lataria, chips). Essa técnica de quebrar o projeto em pedaços é chamada de:
- [ ] Cronograma de entregas
- [x] **Estrutura Analítica do Projeto (EAP)** ✅
- [ ] Termo de Encerramento
- [ ] Relatório de Custos

### 9. O sucesso da criação da empresa Fairchild dependeu do bom relacionamento entre os cientistas, o investidor e o banco. Como chamamos todas as pessoas interessadas ou envolvidas em um projeto?
