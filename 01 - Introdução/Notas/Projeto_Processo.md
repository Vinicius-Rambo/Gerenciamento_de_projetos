# Projeto vs Processo

Para gerenciar o trabalho em uma organização, é fundamental distinguir Projetos de Processos:

## Projeto
É um esforço **temporário** (com início, meio e fim definidos) realizado para criar um produto, serviço ou resultado **único**. Lida com maiores incertezas e atua como agente de mudança. 
*Exemplo:* Desenvolver um novo sistema.

## Processo (Operações)
É um conjunto de atividades **contínuas** e recorrentes. Segue um fluxo padronizado para manter algo funcionando com resultados previsíveis.
*Exemplo:* Emissão de notas fiscais ou realização de backups diários.

## Triângulo das Restrições
O sucesso de um projeto depende de equilibrar três vértices principais:
- **Escopo:** O que será entregue.
- **Tempo:** Quando será entregue.
- **Custo:** Quanto será investido.
O equilíbrio entre esses três fatores é o que garante a **Qualidade** e gera **Valor** para o cliente.
